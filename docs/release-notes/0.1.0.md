# v0.1.0

Initial development release of the read-only AudiobookDB metadata adapter for
Audiobookshelf. Supports title/author searches, exact Audible ASIN resolution,
recording-specific matches, fresh per-request authorization and bounded caching.
Direct Docker networking, localhost/LAN HTTP and optional native TLS are supported.

- Fix HTTP-date Retry-After handling and exact cooldown-cap rounding.
- Dispatch rate-limited upstream reads in order to prevent starvation during
  sustained traffic and recurring cache expiry; preserve existing request limits.
- Run Python regressions alongside local Go race/vet and container checks.
- Report version, commit and dirty state through `/adapter version`, startup logs
  and OCI labels; pin GitHub builds to a tested source SHA.
- Include reproducible sustained-memory checks, linux/amd64 binary and image
  archive, licenses and SHA-256 checksums. Validate the checksums before loading.
- Add Unraid Docker template, profile and icon plus submission instructions.

CI runs locally; GitHub Actions remains disabled. Use Docker Compose source
builds or download/load the image archive. A public registry image and Community
Applications listing are pending publication credentials and Unraid review;
the template's GHCR reference is not advertised as pullable yet.

Major zero indicates initial development. Exact ISBN-only resolution and
duplicate in-flight request sharing remain deferred. Synthetic load results do
not guarantee memory or latency for every production workload. See the bundled
`load.json` for this exact release image's measured results.
